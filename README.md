# SGBD P1.2 - Migración de Hugo + SQLite a Chyrp Lite + SQLite (BrunoAlon)

Repositorio con la resolución de la práctica P1.2 en la rama `chyrp-lite`:
- `tools/migrar.py`: Script ETL transaccional e idempotente para migrar entradas y páginas a Chyrp Lite.
- `tools/test_migrar.py`: Pruebas unitarias de las funciones puras de transformación.
- `Makefile`: Objetivos `make test` y `make migrar`.
- Ejercicios resueltos: Transacciones (Ej. 1), migración de páginas (Ej. 2), extracción desde `build/site.db` (Ej. 3), soporte de autor (Ej. 4), etiquetas numéricas (Ej. 5) y consultas SQL de etiquetas (Ej. 6).
